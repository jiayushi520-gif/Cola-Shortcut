# Cola Shortcut

Version 1.0.0 · MIT · [中文](README.md)

Track one sugar-free cola per local calendar week, rinsing and brushing check-ins, and a one-week penalty for missed brushing deadlines. Check-ins cannot verify actual behavior. Includes weekly/history reports, backup/restore, four launcher shortcuts and an optional Scriptable widget.

Apple-signed files and core execution were tested on macOS 15.7.2. **iOS 26.1 import, Scriptable bookmarks and actual widgets remain unverified.** This is not Apple certification.

Download signed files from `shortcut/` or Releases after publication. Transfer them using AirDrop, open them in Files, and add to Shortcuts. Install ColaManager-Test first, then ColaManager and companion launchers. Keep the main name ColaManager. AirDrop installation does not need an iCloud sharing link; runtime storage still uses iCloud Drive.

Allow file access, Reminders and notifications as requested. The native shortcuts require no Python or always-on Mac. Scriptable is optional and needs an explicitly authorized folder bookmark. Do not assume arbitrary cross-app iCloud paths are accessible. Widgets are system-scheduled, not real-time. Use one writing device at a time to avoid sync conflicts.

Repository: [GitHub](https://github.com/jiayushi520-gif/Cola-Shortcut). Downloads: [Releases](https://github.com/jiayushi520-gif/Cola-Shortcut/releases). RoutineHub and Apple iCloud share links are not available yet.
