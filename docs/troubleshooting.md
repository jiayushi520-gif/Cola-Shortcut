# 故障排查

- 入口找不到主程序：确认安装并保留名称 ColaManager。
- 文件不可用：在“文件”App 下载 iCloud 文件，等待同步；不要用空状态覆盖已有记录。
- 小组件数据不可用：在 Scriptable 授权 ColaManager 文件夹书签，并在 App 内运行一次。iOS 扩展访问仍需实机验证。
- 提醒未送达：检查通知权限和个人自动化；查询和饮用也会重新计算处罚。
- 刷牙超时：补打卡可以记录时间，但不会取消既有处罚。
- 数据损坏：先保存原文件，使用菜单恢复此前备份。不要同时从多台设备恢复。

备份/恢复选择器、锁屏自动化、跨设备同步和 iPhone 导入不在已通过实测范围内，见 TEST_REPORT.md。
