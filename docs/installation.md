# 安装

1. 下载并通过 AirDrop 或“文件”传输签名成品，无需 iCloud 分享链接。
2. 打开 ColaManager-Test.shortcut，添加后运行，预期显示“可乐管理系统运行成功”。
3. 添加 ColaManager.shortcut，保留名称；添加其余七个配套文件。
4. 开启 iCloud Drive，运行主程序“查看本周额度”，按提示授权和初始化。如果已有其他设备数据，先等待同步，不要重新初始化。
5. 授权提醒事项及通知。按 [使用说明](usage.md) 配置个人自动化；按 [小组件说明](WIDGET_INSTALL.md) 添加组件。

iOS 26.1 上述流程尚待实机验证。首次测试可先只查看额度，避免登记虚假饮用记录。原生四入口共用主程序数据，不能脱离主程序安装。
